# WinTuner

**启动项、图标角标、进程注入的开关。** Go 单 exe + 内嵌网页界面，零第三方依赖。

```
wintuner.exe        双击即开界面
wintuner gui        同上
```

## 它做什么

| 标签页 | 管什么 |
|---|---|
| 启动项 | 注册表 Run（HKLM/HKCU/32位）、启动文件夹、开机自启服务、已启用计划任务。一键禁用 / 启用 |
| 图标角标 | Explorer 图标叠加处理器，按来源分组（百度网盘 / 坚果云 / OneDrive / Adobe / 残留）。治"资源管理器一动鼠标就卡" |
| 进程注入 | Winsock NSP。深信服这类客户端即使没运行也会把 DLL 注入所有进程 |
| 诊断 | Explorer CPU 采样、找出同名进程过多的并一键结束 |

## 为什么做这个

这些工具最早是每次需要时临时造的：扫启动项写一份、图标角标开关写一份、
深信服开关再写一份，然后用户忘了它们在哪。

真正的问题是**散落 + 不可逆**。所以这个工具把三件事收进一个界面，
并且每一条禁用都写备份、可还原。

## 关键设计

- **禁用一律可还原。** 注册表值先备份到 `HKCU\SOFTWARE\WinTuner\Disabled`
  再从原位置摘除；快捷方式真的挪进 `D:\Tools\disabled-autostart`（沿用用户
  已在用的"启动项坟场"）；服务记住原 Start 值再改成禁用；计划任务同样。
- **保留原值类型。** 含 `%VAR%` 的命令必须写成 REG_EXPAND_SZ，
  写成 REG_SZ 时变量不会展开，启动项会静默失效。
- **扫描不需要管理员。** 注册表的 `Open` 只要读权限——
  一旦连写权限一起要，非管理员进程连 HKLM 的服务列表都读不了。
- **权限不足如实提示。** 改 HKLM / 服务 / Program Files 都需要提权，
  界面给出"以管理员身份重启"按钮，走 ShellExecute 的 runas 由系统弹 UAC。
- **暴露"残留"注册。** 有些卸载不干净的软件会留下指向不存在 CLSID 的
  叠加处理器，它们占着名额、永远画不出角标。界面把这类排在最前面。
- **只监听回环 + 一次性令牌。** 与 wbmux 同一套约定，防本地 CSRF 与 iframe 点击劫持。

## 一个实测教训，写在这里

最初排查"资源管理器一动鼠标就卡"时，发现 `explorer.exe` 持续烧 37% 单核。
禁用了 24 个图标叠加里的一部分、又关掉了深信服的 NSP 注入，只降到 29%。

**真正的元凶是 23 个卡住的 `SnippingTool.exe`**——用户反复按 Win+Shift+S，
每个都启动了却没弹窗口，堆在那里把 shell 拖住了。杀掉之后降到 1%。

所以"诊断"标签页里有专门一栏：**同名进程过多的**，可一键结束。
一个程序起了十几个实例且大多不干活，几乎总是"启动失败但没退出"。

## 构建

```bash
go build -ldflags "-s -w" -o wintuner.exe ./cmd/wintuner
```

零第三方依赖，`go.mod` 里没有任何 `require`；Windows / Linux / macOS / amd64 / arm64 都能构建。
（注册表、Winsock、进程枚举这些平台功能都是 `syscall` 直调系统 DLL。）

## 免责声明

本工具会改注册表、服务启动类型和 DLL 文件名。虽然每一步都可还原，
**使用前请理解你在关掉什么**。对系统关键进程（svchost、lsass 等）有硬编码保护，
不允许通过界面结束。
